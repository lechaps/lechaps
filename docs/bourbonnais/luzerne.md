# Luzerne

**Une plante fourragère — ce trèfle qu'on cultive pour nourrir les bêtes.** La luzerne, c'est l'aliment de base du bétail, la richesse invisible qui nourrit la richesse visible.

---

## L'exemple

*C'est temps de couper la luzerne pour les bêtes.*

> Il convient de procéder à la récolte de cette plante herbacée afin de sustenter le cheptel exploité.

---

## Le souvenir

La luzerne, c'était l'importance de ce qu'on ne voit pas — tout le travail pour cultiver quelque chose que les bêtes mangent. Mais c'était crucial, c'était la base de tout. Un champ de luzerne bien entretenu, c'était un signe de prospérité, de respect pour le travail. Les vaches étaient grasses parce qu'il y avait de la luzerne. Simple comme ça.
