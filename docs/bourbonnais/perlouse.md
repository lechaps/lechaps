# Perlouse

Une **perlouse**, c'est un pet, mais nommé avec assez de dentelle pour donner au désastre intestinal des airs de bijou de famille. Elle peut être sonore, furtive, traîtresse ou franchement criminelle ; dans tous les cas, elle rappelle que le corps humain, malgré ses prétentions, reste une plomberie susceptible. Le mot a presque quelque chose de tendre, ce qui est beaucoup demander à une chose capable de vider une pièce avant le café.

## Exemple

*Le salaud, il t'a lâché une perlouse… Même les sourds en profitent !*

> « Le misérable vient de libérer dans notre atmosphère commune une effluve si expressive que les personnes privées d'audition peuvent, elles aussi, apprécier pleinement l'ampleur de son intervention. »
